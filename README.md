# 计算机网络与 Web 通信

本项目旨在系统性地梳理计算机网络中与 Web 开发息息相关的核心协议与技术体系。

计算机网络的本质是为了解决“不同机器之间如何可靠共享数据”，整个体系通过分层抽象逐步收敛复杂性：

- 底层由物理设备（网线、路由器、基站等）提供连接能力，构建出局域网与广域网的网络结构
- TCP/IP 提供跨网络的寻址与可靠传输能力
- 进一步由 HTTP 在应用层定义数据交换的语义与规则
- 浏览器则作为执行与安全环境，通过同源策略等机制保障用户使用
- 在“能够通信”的基础上，又通过 HTTP/2、缓存、CDN、HTTPS 等技术持续优化传输效率与安全性
- 最终形成一个从连接、传输到应用与优化的完整通信链路。

## 目录导读：网络演进的五大阶段

### 一、“连得上”：物理互联与传输基石 (Connection & Transport)

从物理世界的网线、路由器到广域网，再到屏蔽底层差异的可靠传输协议。这是网络最底层的基建。

- **[TCP/IP 协议族](./docs/TCP-IP.md)**
  - 互联网的绝对骨干。介绍了四层/七层网络模型、数据从应用层到物理层的封装/解封装过程，以及 TCP 核心的三次握手机制。

### 二、“能说话”：应用层通信标准 (Communication Standard)

基于 TCP/IP 构建起通信双方的连接后，需要一种通用的“语言”来实现数据的获取和共享。

- **[HTTP (超文本传输协议)](./docs/HTTP.md)**
  - Web 通信的基石。介绍了 HTTP 的请求/响应报文结构、常用状态码及核心工作流程。
- **[Web 服务器 (Web Server)](./docs/WebServer.md)**
  - 解析了在服务器端如何接收 HTTP 请求、调度处理逻辑并返回数据的核心组件（代理、网关、缓存等）。
- **[cURL (Client URL)](./docs/cURL.md)**
  - 开发者最常用的轻量级网络请求命令行工具，用于直接测试和发起 HTTP 交互。

### 三、“说得快”：性能与效率的极致追求 (Performance & Efficiency)

随着 Web 数据的爆炸式增长，早期的单向、串行通信已经无法满足需求，技术开始向极致的性能演进。

- **[HTTP 版本演进](./docs/HTTP-Versions.md)**
  - 讲述从 HTTP/0.9 到 HTTP/3.0 的演进历程，重点解析了持久连接、管道化、多路复用以及试图解决的核心痛点（如队头阻塞）。

### 四、“说得安全”：安全与隐私的防御体系 (Security & Privacy)

浏览器作为普通用户接触 HTTP 的最主要宿主，其发展倒逼了网络安全体系的全面升级。

- **[Cryptography (密码学基础)](./docs/Cryptography.md)**
  - HTTPS 的底层基石。涵盖了对称加密、非对称加密、哈希算法，以及现代网络中广泛使用的“混合加密”机制。
- **[HTTPS (安全超文本传输协议)](./docs/HTTPS.md)**
  - 在 HTTP 基础之上加入 SSL/TLS 层，解决了明文传输带来的窃听、篡改和伪装风险。
- **[浏览器安全策略 (Browser Security)](./docs/Browser-Security.md)**
  - 介绍了浏览器保护用户安全的最基础底线——**同源策略 (SOP)**，以及常见的 XSS 和 CSRF 攻击防御。
- **[CORS (跨域资源共享)](./docs/CORS.md)**
  - 在同源策略的“铁壁”上开的“安全门”，详细解析了跨域机制以及 **OPTIONS 预检请求**的链路逻辑。

### 五、“能记住彼此”：状态管理与数据持久化 (State & Persistence)

HTTP 本身是无状态的（打完一次招呼就忘），为了让网络能够支撑复杂的业务逻辑，必须引入状态管理。

- **[Cookie 与状态保持](./docs/Cookie.md)**
  - 解决 HTTP 无状态问题的经典方案，介绍了 Cookie 的核心属性、工作流程及其与 Session/Token 的关系。
- **[SQLite 嵌入式数据库](./docs/SQLite.md)**
  - 介绍了在服务端如何以最轻量的方式（无服务器、单文件）将这些会话状态或业务数据进行持久化存储。

## 项目实践 (Project Practice)

理论需要结合实践。本项目提供了一个简单的客户端与服务端前后端分离的登录交互示例，用于演示和验证网络请求的真实流程。

### [Client (前端客户端)](./Client/)

- 一个原生的 HTML/JS 页面（集成 Bootstrap）。
- 演示了如何通过 `fetch` API 发起 `POST` 请求。
- 演示了如何设置 `Content-Type: application/json` 请求头并携带 JSON 数据。

### [Server (后端服务端)](./Server/)

- 基于 Node.js + Koa 框架构建的轻量级 Web 服务器。
- 演示了如何通过 `@koa/cors` 解决**跨域资源共享 (CORS)** 问题。
- 演示了如何解析请求体 (`@koa/bodyparser`)，并连接 SQLite 数据库 (`sequelize`) 验证用户账密。
- 提供了一个标准的 `/api/signin` 接口，返回结构化的 HTTP 响应状态和 JSON 数据。
